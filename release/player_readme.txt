环球航行 v0.5 —— 怎么玩（15 分钟版）
================================================

一、开始
  1. 双击 ocean-s-king.exe（不用装任何东西）。
     Windows 可能弹一次 SmartScreen（这个 exe 没有数字签名），点「更多信息 → 仍要运行」。
  2. 第一屏是房间：按 1 单机出海（另外三条船交给 AI）；按 2 开房间当房主；
     按 3 加入别人的房间（填房主 IP，回车；中途加入会接手一条 AI 船）。
  3. 开场标题卡按任意键收起来。
  4. 按 . 把时间按到 ×36 —— 不加快进的话，这一趟要走一个多小时真实时间。

二、这一趟要做什么
  5. 左键点一个方向（朝西南、绿岬岛的方向）设目标点；
     或者直接按 N，让航海官沿着航线一段一段开。
  6. 到港口外面按 X 抛锚、P 靠港。港口面板上写着「开到下一个港要几个航程日、
     还缺多少水」，照着买（也可以选「一键补给」）。
  7. 一路开到地图西南角的 圣阿莱克索（巴西）。四条船都到齐，
     船队结算页会自己弹出来（财富 / 航海 / 知识 / 船员 / 历史与政治，三档评价）。

三、键位
  左键 目标点·带队        X 抛锚             1/2/3 帆档        +/− 操帆人数
  L 登陆·返船             P 靠港·港口面板     Tab 帆态面板      C 船员面板（Tab 再切规矩）
  K 知识与日志            N 沿航线走          S 结算页（结完账才有）
  . 快进 ×1/×4/×12/×36    F5 存档             F9 读档           滚轮 缩放 / 沉入船舱

  上岸之后还有两个动作：
    B 向天开枪 —— 会把当地人惹毛（两枪翻脸）；他们翻脸之后，你再走进村落就会被围上来打。
    打起来之后：G 齐射 / 各自为战　H 冲上去　J 慢慢退回海滩

四、卡住了怎么办
  · 船顶着风磨不出前进时，屏幕上会出一条提示 —— 照它说的点一个偏开一点的目标点，
    或者按 N 沿航线走。别对着正逆风硬点。
  · 到了港口记得按 X 抛锚：船还张着帆的话，港外的洋流会把它慢慢推上滩。
  · 靠港状态、船体损伤、开不开得快，按 Tab（帆态）/ C（船员）都看得见。

五、想试一场陆战（约 3 分钟）
  按第 2 步出海 → 往西南的绿岬岛开（时间按到 ×36 大约三分钟）→ 船靠到滩头附近按 X 抛锚、
  按 L 带人上岸 → 左键点地图上的「村落」走过去。
  走到村子会摊开一张卡（部落冲突）—— 选「开火吓退他们」，他们就翻脸了；
  然后你会看见他们**从村子里走出来**（不是凭空冒出来的），两边在百来米外咬上：
  齐射、然后见真章（火枪要装填一分多钟，那一分多钟里只能靠长矛）。
  打输打赢都写进航海日志与最后的结算。
  （不想等卡片也可以：在岸上按 B 向天开枪，两下就把他们惹毛。）

六、联机（局域网，最多 4 个人）
  房主：第一屏按 2。记下自己的局域网 IP（命令行敲 ipconfig，看「IPv4 地址」，形如 192.168.1.23）。
        Windows 第一次会弹「是否允许本应用访问网络」—— 必须点【允许】（专用网络）。
        端口是固定的 UDP 47777，要确认防火墙没挡（弹窗点了取消的话，去防火墙里放行）。
  其他人：第一屏按 3，填房主的 IP，回车。也可以连端口一起填，形如 192.168.1.23:47777。
  条件：两台机器在同一个局域网/路由器下（手机热点也行），别开"客户端隔离 / AP 隔离"；
        跑的必须是同一份游戏（版本对不上会直接告诉你"协议版本不同"）。
  开局就是四艘船：没人开的由 AI 接手，谁中途进来就接手一条；掉线的船不会消失，就地转 AI 继续走。
  注意：买卖与港口库存由房主执行 —— 客户端能看价格、按不下"买"（面板会说明）。
  存档各存各的（F5/F9 存在自己机器上）。

七、存档
  存档写在 %APPDATA%\Godot\app_userdata\环球航行\saves\ 里（F5 存 / F9 读）。
  想重新开始：把那个 saves 文件夹删掉就行。

八、音频
  全部是自产合成音（不用外部素材）；逐条许可说明见仓库里的 assets/audio/LICENSES.md。

—— 这一版是 v0.5 的候选包：跨大西洋一段完整航程 + 局域网 2–4 人 + 船队级结算。
   玩完欢迎把「哪里看不懂 / 哪里卡住 / 哪里不好玩」写下来，比夸它有用得多。
