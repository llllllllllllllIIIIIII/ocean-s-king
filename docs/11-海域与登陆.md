# 测试海域与登陆（Day 6 定稿）

> 前五天做的是"船"和"船上的人"。这一天把它们放进一片海：
> **出港 → 巡航 → 发现岛 → 决定带谁上岸 → 上岛 → 返航**。
> 登陆期间船上交给大副 —— 玩家回来时会收到一份"你不在的时候发生了这些事"。

---

## 0. 一台相机，从整片海滚到船舱

**这里没有"海图场景"和"船内场景"的区分** —— 只有一个相机，滚轮是一根连续的轴：

```
整片海（zoom 0.15，8000 米宽）
   ↓ 滚轮向下
海图 / 战术视角（0.3–4）
   ↓
船（4–40：能看清甲板、帆、索具）
   ↓
船内视图（80 = 40 像素/米，和 Day 2 的船内调试视图是同一个比例）
   ↓ 继续向下
沉进船舱：L1 下层甲板 → L0 货舱 → L3 桅顶瞭望台（向上滚回来）
```

用的是**同一个 `ShipRenderer`**（`px_per_m` 这个参数决定"一米画多少像素"：
船内调试视图是 40，海图是 0.5），所以船永远是那艘 24×7、SVG 拼出来的船，
甲板、房间、物件、船员一个都不少 —— 海图只是把相机拉远了。

> 这一点最早做错了：海图当初是**另一个场景**，船在里面退化成一个占位三角块，
> 船舱也进不去。用户的原话是"我想的是船本身就和你前面做的一样，只是加了点地图的功能"。

## 1. 海域

`data/world/test_sea.json`，8km × 8km（开一圈约 12 分钟）。地形只用**圆**和**带**两种形状：

| 要素 | 形状 | 作用 |
|---|---|---|
| 出发港 | 圆 | 开局位置 |
| 绿岬岛 | 圆（半径 900m，外圈 280m 是沙滩） | 可登陆 |
| 岛上 4 个地标 | 圆 | 滩头 → 内陆遗迹 → 淡水溪流 → 部落村落，每个带一段文本 |
| 暗礁 | 圆（半径 430m） | 撞上去就损伤船体 |
| 洋流带 | 一条带宽 700m 的带子 | 流速 0.9 m/s，把船推着走 |

查询都在 `scripts/sea.gd`：`is_land / is_beach / is_reef / is_port / current_at /
lee_factor / poi_at`。怎么用这些答案是 `scripts/voyage.gd` 的事。

## 2. 风与洋流：两个"船之外"的力

**岛的背风区**：站在岛的下风侧（从岛心往风吹去的方向），风速乘 `lee_factor`（0.45），
越靠近岛越明显。所以绕到岛后面帆会软 —— 这是玩家能摸到的地形影响。

**洋流**：船的受力看的是**相对水的速度**：

```
u_rel = u − 水流在船体系的分量      阻力作用在 u_rel 上
位置积分用的是**相对地面**的速度
```

于是不挂帆也会被流带着走，逆流慢、顺流快。这里踩过一个坑：阻力必须
`hull_drag(|u_rel|) · sign(u_rel)` —— 水比船快时阻力是**推**船而不是拖船，
少了那个符号，洋流一点也带不动船。

## 3. 损伤（三处，每处都能在操船上看见）

| 部位 | 效果 |
|---|---|
| 船体 | 摩擦与兴波阻力 ×(1+0.9·损伤) —— 同样的风跑不快 |
| 桅杆 | 能挂的帆面积 ×(1−0.5·损伤) —— 推力直接掉 |
| 舵 | 转舵效率 ×(1−0.6·损伤) —— 换舷更慢 |

暗礁撞一次：船体 +28%、舵 +10%。

## 4. 登陆流程（docs/01 支柱 6）

```
开到滩头 420 米内 → X 抛锚 → L 打开名单 → ↑↓ 选人 / 空格勾选 / 回车确认
   → 船长 + 选中的人上岸（相机切到状态 C，跟着船长）
   → 船上交给大副：目标点、帆档、船员调度照常跑
   → 岸上左键点地标走过去，走到就记录 + 触发事件
   → 走回滩头按 L 上船：一次性收到"你不在的时候"的报告
```

**带走的人真的离船**：他们在名册里被标成"上岸"，不参与船上的派活 ——
所以带走的每一个人都意味着船上少一双手。实测：带走水手长/大副/木匠/舵手 + 6 名水手后，
操帆手艺从 0.71 掉到 0.59，收放速度从 7.0 掉到 6.0 度/秒。

## 5. 五个脚本事件与那条因果链

| 事件 | 触发 | 后果 |
|---|---|---|
| 瞭望员报告 | 离岛 < 2600m | 第二幕文本，岛上目标点变成可探索 |
| 风向突变 | t > 300s | 风向转 55°，船头被压向下风 |
| 触礁 | 船体进入暗礁（未抛锚） | 船体 28% / 舵 10% 损伤 + 报告 |
| 船员伤病 | 触礁之后 | 甲板上的人受伤，外科医生接手 + 报告 |
| 发现遗迹 / 部落接触 | 走上对应地标 | 各有报告（延迟交付） |

**可见的因果链**（验收第 4 条）：

```
风向突变 → 航线被压向暗礁 → 触礁（船体受损）→ 木匠的修补优先级生效
                                        ↘ 有人受伤 → 外科医生接手
```

这条链子不需要脚本硬连：风转了 → 航海官还按老目标划 → 船自己飘进礁区 →
损伤进了物理 → 船员的需求系统自己把木匠派去修补。

**延迟消息**：船长在岸上时，船上发生的事不弹窗，攒进 `pending_reports`；
回船时 `return_to_ship()` 一次性交给他（"你不在的时候，船上发生了：…"）。

## 6. 怎么玩 / 怎么验

```powershell
$g = 'D:\Godot\Godot_v4.7.2-stable_win64_console.exe'
& $g --path . res://scenes/sea_debug.tscn              # 自己开一趟
& $g --path . res://scenes/sea_debug.tscn -- shots     # 自动跑一趟并截图（20–30）

```

操作：左键设目标点 / 岸上带路，X 抛锚，1/2/3 帆档，+/− 人数，**L 登陆/返船**，
↑↓ 选人、空格勾选、回车确认，Tab 帆态面板，C 船员面板，**`.` 快进一分钟**，
**滚轮：整片海 ⇄ 船 ⇄ 船舱**。

四条验收的证据：

| 验收 | 证据 |
|---|---|
| 走通出港→巡航→发现岛→挑人登陆→上岛→返航 | 截图 20→21→22→23（船）→24（甲板细节）→25（船舱）→26→27→28（登陆名单）→29→31；测试里逐步断言 |
| 登陆期间船上发生了玩家没控制的事，回来有报告 | 船长在岸时触礁+伤病，`pending_reports` 2 条，回船一次性交付 |
| 带走的船员影响船的操控 | 手艺 0.71→0.59，收放 7.0→6.0 度/秒 |
| 至少一条事件因果链可见 | 风向突变 → 触礁 → 船体损伤 → 木匠修补（测试逐环断言） |

## 7. 已知粗糙处

1. **船不会避礁**：航海官只会算风向与死区，不会绕开暗礁 ——
   现在这正好是那条因果链的来源，但真做游戏得给它加一条"避开已知危险"的规则。
2. **岛上没有障碍与地形**：地标是圆，走直线就到，没有林地/山丘。
3. **部落接触只是一段文本**，没有交易与分支（Day 7 的剧本再说）。
4. **船长一个人走**：随行船员不上岛（只在人数上计数），岸上看不到队伍。
5. **没有昼夜与时间压力**：快进键直接把游戏时间推过去。

## 8. 三处按反馈修掉的问题（2026-10-01 试玩后）

| 现象 | 根因 | 修法 |
|---|---|---|
| 海图上的船是"粗化的三角块"，不是原来那艘细化的船 | 海图用的是占位标记（`_draw_ship_marker`），没接真正的渲染器 | 给 `ShipRenderer` 加 `px_per_m`（船内视图 40、海图 0.5），**海图和船内视图共用同一个渲染器**；拉远到看不见船时补一个定位光圈 |
| 登陆名单面板跑偏、找不到 | 面板画在**世界坐标**里，跟着相机跑 | 抽成 `scripts/landing_picker.gd`（Control），挂在 CanvasLayer 上居中显示 —— 和其它面板一个做法 |
| 船能开到陆地上 | 压根没有陆地碰撞 | `ShipDynamics` 加圆形陆地判定 + 沿轴滑动（撞岸贴着滑，不插进去也不停死）；蹭滩给 6% 船体损伤与提示；队伍在岸上也只能走到岛内 |
