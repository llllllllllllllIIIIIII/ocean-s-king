## 1. 这一版要做什么

**一句话**：把"四个船长在同一个大西洋上走完一段航程"，变成
**一支远征船队从 1519 年出发、绕地球一圈、1522 年带着一份历史评价回来**。

### v1.0 完成时，能演示什么

1. 单人（1 人 + 3 条 AI 船）或联机（2–4 人各一条船）从圣卢卡尔出发，**逐段开到**巴西、
   麦哲伦海峡、横渡太平洋、到香料群岛、绕过好望角、回到西班牙 —— 全程可航，不是海图上的几个点；
2. 海上会**真的打起来**：实时舷炮齐射、链弹打帆、硝烟遮视线、接舷跳帮；
3. 葡萄牙会**追捕**你：被发现 → 跟踪 → 警告 → 驱逐 → 拦截 → 攻击，你能跑、能谈、能打、能骗；
4. 三年里四十个人会饿、会病、会闹、会逃、会叛；规矩十条管得住一部分，管不住另一部分；
5. 走到最后拿到一份**船队级五类成果**，加上**四档结局** —— 完成环球，不一定是成功的远征。

### 与 v0.5 的关系

v0.5 立住了四条地基：**状态三层**（docs/14）、**世界分块**（docs/15）、
**局域网权威**（docs/16）、**指挥链路 + 陆战火器**（docs/09、docs/19）。
v1.0 **一次都不推翻它们**：

| v0.5 的地基 | v1.0 怎么用 |
|---|---|
| 地图压缩 1 km = 125 km | 直接用到全球：**320 km × 160 km = 200 块 tile**，几何比例一个数不改 |
| `WorldMap` 的 tile 索引 + circle/band 原语 | 只往里加全球海岸线数据，**查询签名不变** |
| 状态三层与星型网络 | 只加字段与消息（docs/22 第 4 章），拓扑不变 |
| 指挥链路（玩家→航海官→船员→帆） | 三年远征里它是唯一的操船方式，不改 |
| 陆战的实时小队 + 火器弹道 | **舷炮海战直接复用这套框架**（炮组当单位） |

### 为什么 v1.0 要排这么多期

v0.5 让原设定 44 节里的约 28 节有了落地（22 节完整 + 6 节部分实现）。
v1.0 要动的是 **31 节**（逐节对照在 `docs/22` 附录 A 与本文件第 13 节）——
其中一部分是把那 6 节"部分实现"补齐，其余是从零新做；
另外 12 节完全不用动、1 节只体现在文档里。
其中两个是"不确定性 ±50%"的大块：**M10 实时舷炮海战**与**M13 太平洋的长期远征**，
所以它们排在内容期之前 —— 与 v0.5 把 M3（网络）M6（陆战）提前是同一个道理。

## 4. 分期详细卡片

### M9 · 全球海图地基

**目标**：把 3×3 块的大西洋，换成**整个地球的 320 km × 160 km**，
并且让"同一坐标在任何 tile 采样结果一致"这条硬指标在 200 块上依然成立。

**任务**

| 项 | 内容 |
|---|---|
| 数据格式 | `data/world/global/*.json`：大陆海岸线（长 band 折线）、岛群（circle）、海峡、暗礁、洋流带、季风带；沿用 circle/band 两个原语，**不加多边形** |
| 全球索引 | 20×10 = 200 块 tile；索引仍按**影响范围**登记；`Sea` 的七个查询**签名一字不改** |
| 分区图幅 | 全球海图 = 一张 320×160 的总图；关键区域各有放大图幅（伊比利亚 / 加勒比 / 海峡 / 太平洋岛链 / 香料群岛 / 好望角） |
| 预载 | 相机拉远到底看到全球图；玩家在局部视图里开到 tile 边界时相邻 8 块已预载 |
| 航线数据 | `routes.json` 从 3 段扩到全球分段，每段带 `real_km_per_map_km`（高纬度修正）、风险/补给/价值 |
| 快进 | 新增 **×144** 档（现有 ×1/×4/×12/×36 之上） |

**产出物**：`data/world/global/*.json`、`scripts/world_map.gd` 的全球索引、`scripts/chart_view.gd` 的分区图幅、`tests/test_globalmap.gd`、一组跨洋截图。

**验收标准**

1. `tests/test_globalmap.gd`：全球航线上的采样点（每 250 米）在**索引版与全扫版**下逐字段相等；
2. 一条命令无头跑"圣卢卡尔 → 摩鹿加"的航线，不出现"必须穿陆地"的缝、不出现地形跳变；
3. 全球 200 块的索引构建耗时与内存有数字（写进实际记录），远洋空海的 `test_perf` 不高于基线；
4. 既有 20 条通道全绿（`test_world` 的迷你海域回归不许退化）。

**砍单预案**：关键区域手工 + 其余海域用一个极简的全球陆地掩码；
海图只做一张总图不加分区图幅；`real_km_per_map_km` 全局一个数。

**这一期的第一个动作**

1. 先确认 v0.5 那三件事的状态（发 Release / 真人试玩 / 双机）；
2. 跑一遍本文件第 1 节的基线，确认全绿；
3. 把 `Sea` 的七个查询从"只认大西洋特征"扩到"认全球特征"，**先立全球数据文件与索引，再填内容**。

**目标**：让"海上打起来"是真的打起来 —— 炮组、装填、弹种、距离、机动、硝烟、跳帮。

### M11 · 势力 · 追捕 · 外交

**目标**：世界不再只有风和礁 —— 有人、有势力、有政治。

| 葡萄牙追捕 | 六环状态机：被发现 → 跟踪 → 警告 → 驱逐 → 拦截 → 攻击；甩掉、谈判、伪装、改线、战斗五条应对 |
| 当地文明扩 | 从"一个文明一条记录"扩到**多群体各一条**（同一文明内部可以态度不同） |
| 王室命令 | 3–5 条硬指标（开局摊开给玩家看），完成/违抗都进世界记忆与结局档位 |
| 抽象 NPC 船 | 商人/海盗/其他航海者的航线与遭遇（复用 `abstract_ship.gd` 的形状） |

5. 联机：势力态度与追捕环由房主推进，客户端看到同一个值（双进程对账加一组）。

**砍单预案**：追捕线先只做"被发现 → 跟踪 → 拦截"三环；王室命令减到 2 条；

## 11. 明确不做（写在这里，防止范围膨胀）

- **Steam 发行**、成就、云存档、Steamworks、商店页素材；
- **英文本地化**与任何本地化框架（中文写死）；
- **多边形海岸**（只用 circle / band 两个原语；需要时才加）；
- **多人共乘一条船**（每人一条船；一个人上岸时他的船交给 AI / 大副）；
- 精确军阵、阵型控制、信号旗系统；
- 船厂/造船/买新船（船只有那四艘远征船 + 沉没/拖带）；
- 攻城、要塞攻防、大规模军阵作战；
- 完整海军军官养成 / 科技树；
- 存档向后兼容（走同一口径：不承诺兼容，但要说人话）；
- mod 支持、创意工坊；
- 手机 / 主机 / 网页导出（只做 Windows）。
- 港口的分昼夜与潮汐（1519 年真实港口要等潮水，但这一层不产生新的决策，不做）；
- 陆战的战场地形 / 掩体 / 建筑（单位继续只按距离与士气行动）；
- 断线重连的"完整状态补发"（重进仍然是"重新领一条船"，与 v0.5 同口径）。
