# 船员社会 · 规则制度 · 道德抉择（v0.5 · M5）

> 这一期的目标是让"船上那四十个人"从**数值**变成**会闹的人**，
> 并且让玩家用**规则**而不是用鼠标去管他们。
> 对应 `docs/13-v0.5开发计划.md` 的 M5 卡片；资源与消耗见 `docs/17`，
> 状态边界见 `docs/14`，联机见 `docs/16`。

---

## 1. 先做规则，再做人

验收第 1 条要的是"**改规则 → 数值真的变**"。那就必须让规则直接给出乘数与偏移，
而不是把影响散在各处的事件里 —— 散着写的话，改一条规矩会牵动多少系统谁也说不清。

所以 `Rules` 刻意做得很薄：**它只是一张"档位 → 数值"的表**
（真源 `data/defs/rules.json`），六条规矩、每条 2–4 档：

| 规矩 | 档位 | 关键数值 |
|---|---|---|
| 口粮制度 | 足量 / 减半 / 严格配给 / 优先关键岗位 | 食物 ×1.0 / ×0.5 / **×0.35** / ×0.7；疲劳 ×1.0 / 1.15 / **1.3** / 1.12；心情 +0.02 / −0.04 / **−0.09** / −0.05 |
| 饮水制度 | 足量 / 严格配给 / 只够做饭 | 水 ×1.0 / 0.6 / **0.35** |
| 值班制度 | 三班倒 / 两班倒 / 全员当值 | 疲劳 ×1.0 / 1.22 / **1.5**；效率 ×1.0 / 1.08 / 1.18 |
| 酒类规定 | 按量配给 / 不禁止 / 禁酒 | 心情 +0.03 / +0.06 / −0.08；紧张度 ×0.95 / 1.15 / **1.25** |
| 宵禁 | 不设 / 入夜后不许上甲板 | 紧张度 ×0.85；纪律 +0.08 |
| 处罚制度 | 宽纵 / 从例 / 严刑 | 纪律 −0.10 / 0 / **+0.18**；紧张度 ×1.1 / 1.0 / **1.3** |

合成规则：**心情相加、消耗与疲劳相乘、纪律相加**。
一条规矩同时压到三个系统上，这正是"用规则管人"的代价与乐趣。

## 2. 社会这一层

`scripts/society.gd`。三个量 + 一张事件表：

```
关系   relations["a|b"] = {affinity: −1..1, favors, grudge}   （12 名关键船员两两之间，共 66 对）
紧张度 tension  0..1      每天 +0.02 + (1−平均心情)×0.06 + 饥饿 0.08 …，再乘规矩的 tension_mult
纪律   discipline 0..1    往"0.5 + 规矩的纪律加成 + (平均心情−0.5)×0.4"靠
```

关系的三条动力学（都是可断言的数）：

- **一起干活** → 好感 +0.02/天（一起值班的人越走越近）；
- **饿着肚子** → 好感 −0.05/天（饿的时候什么都难看）；
- **有人受伤** → 好感 +0.03/天（帮忙的人记在心上）。

**三个小群体**（照砍单预案把派系降级）：军官与绅士 / 水手 / 见习与侍童。
每个群体有自己的凝聚力，跟着"这个群体里人的平均心情"走 ——
所以一份严格配给会同时压低三个群体的凝聚力，而"优先关键岗位"只保住了军官那一伙。

## 3. 事件：按严重度递进

事件不是随机抽的，是**紧张度 + 纪律 + 规则**这三个量越过阈值挑出来的
（没有随机数 —— 无头可测、联机可复现，和 M6 "不用随机数" 是同一条纪律）。

| 严重度 | 事件 | 触发（除紧张度下限外） | 后果 |
|---|---|---|---|
| 1 | 争吵 | 紧张 ≥ 0.35 | 心情 −0.02、纪律 −0.02、那一对关系 −0.08 |
| 2 | 消极怠工 | ≥0.45，纪律 < 0.58 | 纪律 −0.06 |
| 2 | 赌博 | ≥0.50，没禁酒 | 纪律 −0.07，心情 +0.02（短暂的乐子） |
| 3 | 酗酒 | ≥0.55，酒不禁 | 纪律 −0.09 |
| 3 | 偷窃 | ≥0.60，缺粮 | 心情 −0.05，关系 −0.12 |
| 4 | 打架 | ≥0.65 | 心情 −0.06、纪律 −0.06、**有人受伤 15%** |
| 5 | 违抗命令 | ≥0.72，纪律 < 0.45 | 纪律 −0.12 |
| 6 | 逃亡 | ≥0.82，看得见陆地 | **少两个人**（带着口粮） |
| 7 | 叛乱 | ≥0.92，纪律 < 0.35 | 心情 −0.20、纪律 −0.30 |

每次事件之后紧张度会掉一截（−0.02 到 −0.25）、并进一段冷却
（0.8 天 × (1+0.4×严重度)）—— 于是社会停在一个"每隔几天出一回事"的节奏上，
而不是一路烧到叛乱。

## 4. 三个高压抉择

`data/defs/dilemmas.json` + `scripts/dilemma.gd`。每个抉择 **4 个选项**，
每一条后果都是数（船员状态 / 关系 / 纪律 / 结局分数），而且**选 A 与选 B 之后
状态必须真的不同** —— 这条被测试逐项断言，不做只在文案上不同的选项。

| 抉择 | 触发 | 四个选项（各带不同的后果） |
|---|---|---|
| 缺粮 | 出现短缺 | 官兵同份（士气 +、军官 −）/ 先保关键岗位（水手 −0.12 心情、关系 −0.18）/ 抄底舱查私藏（纪律 +0.12、关系 −0.22）/ 偏离航线靠岸找吃的（疲劳 +、知识 +） |
| 重伤病 | ≥2 人重伤 | 把药都给他们（用掉最后一瓶药）/ 交给外科医生判断 / 靠岸把人留下（少两个人）/ 掉头送他们回去（航行分 −3） |
| 部落冲突 | 接触过村落 | 交换（历史 +2）/ 退回海滩 / 开火吓退（消耗火药 1 桶 + 铅弹 10 磅，历史 −2）/ 抓一个当向导（航行 +2、历史 −3） |

抉择的后果里有一项是 **结局分数**（`Voyage.ending_score`：财富 / 航海 / 知识 /
船员 / 历史 五类）—— M8 的结算页直接读它。所以"抓一个向导"不会当场罚你，
但它会挂在你的历史那一栏上。

## 5. 面板：把"为什么"说清楚

`C` 打开船员面板，右半边是 M5 新增的：

```
紧张 30%  纪律 59%  事件 1        规矩（Tab 切换到这里，←→ 改档位）
                                  口粮制度   足量
                                  饮水制度   足量
                                  值班制度   三班倒
                                  酒类规定   按量配给
                                  宵禁       不设
                                  处罚制度   从例
                                  船上三伙人：
                                    军官与绅士：凝聚 76%  心情 77%
                                    水手：凝聚 75%  心情 76%
                                    见习与侍童：凝聚 76%  心情 77%
  若昂·费雷拉 为什么心情差：
    跟 吉列尔莫·塞拉 不对付（−0.24）
```

`Society.why_unhappy()` 的顺序是刻意的：**先说身上（饿/累/伤），再说人际
（跟谁不对付），最后才是规矩（玩家自己定的那几条）** —— 玩家看完就知道该动哪一样。

## 6. 怎么验证

```powershell
& $g --headless --path . --script res://tests/test_society.gd   # 69 项
```

| 验收 | 证据 |
|---|---|
| 1. 改规则 → 数值真的变 | 同一场景只改口粮（足量 vs 严格配给 + 两班倒）跑 2.5 游戏小时：**吃得少**（严格配给 < 足量的 60%）、**更累**（疲劳 +15% 以上）、**心情更差**、**抱怨变多**；饮水制度同样改得动水的消耗 |
| 2. 每个抉择 ≥4 条后果不同的选项 | 三个抉择各 4 条，每条后果 ≥2 项数；"官兵同份"与"先保关键岗位"的士气差 > 0.05、纪律差 > 0.02、结局分数不同；"交换"与"开火"的历史分不同、旗标不同、火药真的少了一桶 |
| 3. 8 小时游戏时间里自然出现 ≥1 次事件 | 默认规矩下跑 8 游戏小时 → **17 次**事件（最后一条是"逃亡"）；另外断言"紧张度越高，挑中的事件越重"（0.40 → 争吵，0.70 → 打架） |

画面证据：`.shots/44_crew_and_rules.png`（面板右半边：规矩、三伙人、为什么心情差）、
`.shots/45_dilemma.png`（抉择卡）。

## 7. 已知限制

| 限制 | 说明 | 什么时候 |
|---|---|---|
| 社会是**每条船各自的** | 它进 `ShipState`，不上网：别人船上的四十个人闹成什么样，你看不见（`docs/14` 的 UI 规矩） | 设计如此 |
| 没有信仰 / 政治倾向 | 原设定第十四节列了十项属性，切片只做心情/疲劳/饥饿/健康/关系 | v0.6+ |
| 抉择不暂停时间 | 卡片摊开时船还在走（快进时尤其明显）—— 这是刻意的：海上没有暂停键 | 设计如此 |
| 关系只在 12 名关键船员之间算 | 28 名普通船员按群体算，不逐个建关系（40×39 对没有意义） | 设计如此 |
| 事件不会自己"平息" | 只有事件本身与补粮能降紧张度；没有"船长讲一段话安抚全船"这类主动手段 | M7 事件池 |

## 8. 这一期踩到的坑

| 坑 | 症状 | 对策 |
|---|---|---|
| 测试两局都"吃光就停" | 存货只有 120 份，两局都在第一个小时吃光 → 消耗量看起来一模一样 | 测试先补足存货，再比"累计消耗" |
| 饿着肚子跑关系测试 | 缺粮让**所有**关系一起变差，于是"一起干活关系变好"被淹掉 | 先补粮再测关系；同时也说明了：饥饿是这一层最强的力 |
| 抉择的 `flag` 写在 `effects` 外面 | "交换"那条选了不留旗标（其他条都写在里面） | 写进 `effects`；数据形状必须一致，不然只有一条会安静地失效 |
| 面板里 `box.position + Vector2(x, y)`，而 y 里已经含了 box.position.y | 选项整体往下偏了一个面板高度，压在提示行上 | 位置要么全相对、要么全绝对，别半半 |
