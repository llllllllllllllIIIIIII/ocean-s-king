## 1. 五类成果：结算页是"账的封面"

`scripts/settlement.gd` **不产生任何新状态** —— 它只是把六期攒下来的账摊开：

| 类别 | 数据来自 | 怎么算分 |
|---|---|---|
| **财富** | `cargo`（金币 + 货按基准价折价）、`memory`（贸易/打捞次数）、`ending_score.wealth` | 折价/100 + 抉择分×5 |
| **航海** | `journal.distance_km` / `nav.beat_count`、`discovered` 的分块数、`journal.landfalls`、`knowledge` 里到过的港 | 里程/4 + 分块×3 + 港口×5 |
| **知识** | `knowledge` 八类条目、`ending_score.knowledge` | 条数×3 + 抉择分×5 |
| **船员** | `roster`（生还/阵亡/带伤/平均心情）、`society`（纪律/事件数）、`ending_score.crew` | 生还 − 阵亡×12 − 带伤×3 + 心情×20 + 纪律×20 + 抉择分×5 |
| **历史与政治** | `ending_score.history`、`memory`（毁约/杀伤）、`culture` 的态度、`story` 的结局旗标 | 抉择分×5 − 毁约×6 − 杀伤×5 |

**三档评价**：总分 ≥220（且**四条船都到）→ 巨大荣誉；≥120 → 普通成功；否则失败式归来。

**全队结算**：`Settlement.fleet_report()` 把四条船各自"到没到巴西、船体多少、几个人、装了多少"
列成一张表。**"巨大荣誉"要求全队抵达** —— 这是 docs/13 第 2 节第 11 条（"4 艘船都到达才完成"）
在代码里的样子。为此 M8 把 `default_destination()` 从"第二个港"改成了**终点港**，
不然 AI 船开到加那利就停，那条验收永远签不了。

## 2. 音频：自产，不下载

`tools/gen_audio.py` 合成七条 WAV（环境：风、浪；交互：抛锚、调帆、开炮、锤击；主题一首），
`assets/audio/LICENSES.md` 逐条写清来源与许可。

**为什么不是找 CC0 素材**：铁律 13 的实质是"来源与许可清清楚楚"。自产天然满足，
而且体积小（七条约 2 MB）、可复现（LCG，不用 `random`，重跑得到同样的文件）、
可调（想更闷更慢改参数重跑）。这是一个**有意做的取舍**，不是偷懒 —— 记录在此，
将来要是想要真人演奏的素材，随时可以替换，接口只有 `AudioDirector` 一个。

`scripts/audio_director.gd` 只读 Voyage：环境音的音量由"真风速 × 天气"与航速推出来，
一次性音效盯着状态变化（抛锚/调帆/开炮/修船）。

## 3. 性能：先把数字量出来

`tests/test_perf.gd`（本机实测，RTX 4060 笔记本 + Godot 4.7.2 headless）：

| 局面 | 平均 | 最坏 | 吞吐 |
|---|---|---|---|
| 停船（4 船 + 40 人名册 + 天气 + 事件池） | **0.367 ms/步** | 1.46 ms | 2723 步/秒 |
| 最重（+ 满帆航行 + 风暴 + 10 对 10 陆战） | **0.683 ms/步** | 1.88 ms | 1464 步/秒 |
| ×36 快进的一帧（12 个逻辑步） | **约 4.5 ms** | —— | —— |

结论：逻辑侧离 60 帧（16.6 ms/帧）还有 3 倍余量，离 30 帧（33 ms）有 7 倍余量 ✔。
**渲染**没在这里量（引擎的事），但四船同屏画的是同一套 SVG 渲染器，v0.1 已经跑过。

## 4. 打包与发布（**这一步需要用户拍板**）

`tools/package_win.ps1`（纯 ASCII，见 AGENTS.md 的坑表）做四件事：
检查导出模板 → 写 `export_presets.cfg`（这个文件在 `.gitignore` 里，所以脚本自己生成）
→ `--export-release` 出 `export/ocean-s-king/ocean-s-king.exe` → 压成
`export/ocean-s-king-v0.5-win64.zip`。

**现在的状态**：脚本能跑，但会停在第一步并退出码 2 ——
导出模板（约 130MB）不在仓库里，装它要联网下载，而 `docs/13` 第 12 节把这件事
列为**需要用户批准**的三件事之一。所以：

```powershell
# 装完导出模板之后（Godot → 编辑器 → 管理导出模板 → 下载并安装）
powershell -ExecutionPolicy Bypass -File tools/package_win.ps1
```

## 5. 验收标准的现状

| 验收 | 现状 |
|---|---|
| 1. 两台机器 2–4 人走到巴西，拿到船队级结算 | **可计算的那一半已验**（`test_settlement` 41 项 + M3 的双进程对账 22 项）；真人那半边要用户跑（见下面"要用户做的事"） |
| 2. 帧率 ≥60（下限 30），并给出 `test_perf` 的数字 | ✅ 逻辑侧 0.68 ms/步、×36 一帧 4.5 ms |
| 3. 没装 Godot 的机器解压 zip 能玩 | ⏸ **卡在导出模板**（用户批准下载后才能产出 zip） |
| 4. 陌生人 15 分钟能上手 | ⏸ 只能真人做（M0 从 10-01 起一直挂着） |

   我再发 GitHub Release（验收第 3 条）；
3. 两台机器各跑一次（开房 / 加入），签验收第 1 条的真人那半边。
