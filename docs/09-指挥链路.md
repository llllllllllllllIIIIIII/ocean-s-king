# 指挥链路（Day 4 定稿）

> 这是本作最重要的设计取舍：**玩家不能直接操船。**
> 玩家只选目标点、选帆档、调人手；怎么走是航海官的事，帆怎么收是船员的事。
> 于是"船员好不好"直接等于"船灵不灵" —— 这条链子把船员系统和操船系统焊在了一起。

---

## 1. 链条

```
玩家                    航海官                     船员                      船
────────────────────────────────────────────────────────────────────────────────
点目标点 ─┐
选帆档   ─┼─→ 航法决策         ─→ 收放帆（慢、准头有限）─→ 帆的气动力
抛锚     ─┤   （保持/转向/抢风/       打舵（有速度才灵）      ↓
调人手   ─┘    顺风/停船）                            → 船体动力学 → 位置/艏向
                    │                                        │
                    └──────────── 帆态面板（Tab）←───────────┘
```

代码对应：

| 环节 | 文件 | 它**不**做什么 |
|---|---|---|
| 指令 | `scripts/orders.gd` | 不知道风、不知道船在哪 |
| 航法决策 | `scripts/navigator.gd` | 不碰帆、不碰舵、不碰船 |
| 执行 | `scripts/crew.gd` | 只能通过 `set_sail_chords` / `set_rudder` 影响船 |
| 物理 | `scripts/ship_physics.gd` | 只管力，不持有位置与速度 |
| 运动 | `scripts/ship_dynamics.gd` | **唯一**能写船的位置与速度的地方 |
| 表现 | `scripts/ship_renderer.gd`、`scripts/sail_panel.gd` | 只读 |

`tools/check_motion_ownership.py` 静态守着最后那条：谁都不能绕过这条链子直接推船。

## 2. 玩家能下的命令（全部）

| 命令 | 操作 | 说明 |
|---|---|---|
| 设定目标点 | 鼠标左键点海面 | 唯一的"操船"命令：往哪儿走 |
| 微调目标 | ← / → 或 A / D | 在船前方放一个目标点 |
| 保持当前航向 | 空格 | 清掉目标点，守住现在的头 |
| 帆档 | 1 / 2 / 3 | 全帆 / 缩帆（55% 帆面）/ 收帆（0） |
| 抛锚 / 起锚 | X | 锚把船摁住，帆的力照样算但推不动船 |
| 调人手 | + / − | 派几个人去操帆（0–12） |
| 帆态面板 | Tab | 看"船为什么慢" |

就这些。没有"直接下舵"，没有"直接调帆"。

## 3. 航海官的决策（Day 4 版）

每一步重新算一次，规则只有三条：

1. **目标不在死区里** → 直接朝目标走（航法：转向 / 顺风跑）。
2. **目标在死区里**（方位与风向的夹角 < 37° + 8° 余量）→ **抢风**：
   贴着死区边界外侧走，选离目标更近的那一舷。
   船一旦越过目标的正横，方位角自己就转出死区，规则 1 接管 —— 换舷是自然发生的。
3. **速度不够（< 2 m/s）** → 先把帆稍微松一点（边界外再加 30°）**攒速度**，
   等速度起来再往上顶。真实水手也是这么干的：船慢的时候贴不住风，
   横着漂的代价（诱导阻力）大得可怕。

**换舷迟滞 12°**：另一舷要"明显更好"才换。没有它，目标几乎正顶风时两舷的优劣
会在零点附近来回翻，航海官一秒换一次舷，船原地打转永远攒不起速度
—— 这是 Day 4 现场抓到的死循环，回归测试见 `tests/test_command_chain.gd` 的抢风那一条。

## 4. 船员的执行（"船灵不灵"的来源）

**收放速度**（度/秒）：

```
rate = (1.2 + 9.0 × 手艺 × 人手系数) × (1 − 0.55 × 疲劳)
人手系数 = clamp(派去操帆的人数 / 6, 0.15, 1.6)
```

满编好手（手艺 0.9、6 人、疲劳 0.1）≈ 9 度/秒，一次换舷三十几秒；
累垮的三个人（手艺 0.35、2 人、疲劳 0.7）≈ 1.4 度/秒，要两分钟。

**准头**（精度）：实际的帆角会偏离目标，
`偏差 = ±((1 − 手艺) × 9 + 疲劳 × 7)` 度，用一条慢摆的正弦表示"手在抖"
（可复现，不是随机数）。偏差超过 6° 时帆态面板会直接说"船员没调好"。

**疲劳**：帆没收好时累积、收好后慢慢恢复。数值很小（一小时连续作业约 0.4），
Day 5 接上真实船员表后才会成为真正的压力。

## 5. Day 4 补的三个物理/机制

| 补的东西 | 为什么 |
|---|---|
| **前进方向按质量积分**（`SURGE_MASS_FACTOR`）| 原来速度是"瞬时跳到稳态"，60 吨的船 0.3 秒换完速，一顶风立刻停死。有了惯性，换舷才能带着余速穿过死区 |
| **诱导阻力只取"轴向分量"**：`abs(F_lat)·abs(u·w)/(u²+w²)` | 原来把横向力整个算成前进阻力，船横着漂时前进被凭空按住 —— 停着的船永远起不来。小侧滑角时它与经典的 `F_lat·tan(侧滑角)` 等价，所以极坐标标定不变 |
| **帆档 / 抛锚真的接进物理** | 缩帆 = 帆面 ×0.55，收帆 = 0，抛锚 = 速度被摁住。不是换个数字，是受力真的变了 |

另外修掉一个藏得极深的符号错误：**左舷受风时帆会被收到迎风面**。
攻角必须按舷别取符号（`ShipDynamics.wind_side()`），否则右舷受风一切正常、
一到左舷推力骤降 —— 这也是"船速永远是 0"的另一半原因。
