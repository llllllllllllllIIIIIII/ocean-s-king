# 陆战 · 火器 · 当地文明（v0.5 · M6）

> 这一期让"带人上岸"变成一件有风险的事：火绳枪要装填、轻型炮要人抬、打起来真的会死人。
> 对应 `docs/13-v0.5开发计划.md` 的 M6 卡片与第 6 节（武器真源 + 四项硬指标）；
> 弹药账在 `docs/17`，伤亡的社会后果在 `docs/18`。

---

## 1. 先做纯模型，再做陆战

和第 3 期（气动）一样的顺序：**四项硬指标全是"数"的问题**，混在寻敌与走路里调，
永远说不清是模型错了还是队伍走错了。所以：

```
data/defs/weapons.json   真源（铁律 12）：口径、装填、射程、哑火率、弹种
scripts/ballistics.gd    纯模型：命中 / 伤害 / 哑火 / 齐射 / 硝烟（不碰地图与单位）
tools/weapons_prototype.py  离线标定：验四项硬指标 + 打命中率查表 + 扫参数
scripts/weapons.gd       把火器接到货舱（谁扛什么枪、一发吃多少弹药）
scripts/land_battle.gd   单位与遭遇（位置、装填、士气、伤亡）
```

`python tools/weapons_prototype.py` 现在跑出来的结果：

```
[PASS] 火绳枪装填 ≥30 秒（最熟练也有 31 秒）    [PASS] 隼炮每发 ≥120 秒（140 秒）
[PASS] 射速 ≤2 发/分钟（1.95 发/分钟）          [PASS] 密集齐射是各自为战的 3.17 倍
[PASS] 干燥哑火率 ≤5%（3.5%）                   [PASS] 大雨哑火率 ≥30%（31.5%）
[PASS] 火药受潮 → 打不着                        [PASS] 霰弹砸船只有实心弹的 8%
[PASS] 霰弹只对 80–200 米内的人有杀伤           [PASS] 实心弹打人几乎没用（0.09）
```

并且生成 `data/defs/weapons_table.json`（36 行命中率查表，给调参看趋势用，
运行时不读它 —— 免得又冒出一个真源）。

## 2. 三项实现约定（docs/13 第 6.3 节）

1. **不用随机数**：命中是"技能 × 距离 × 队形 × 武器"的查表；哑火用
   `(射手, 第几发)` 的整数哈希当确定性硬币 ✔ 所以"同样的初始状态 → 同样的伤亡名单"。
2. **判定归属**：射击方只广播"谁向谁开火"，命中由**受击方所属的权威**判（联机时用）。
   v0.5 只做到"接口摆好、单机可跑"，真正的双机对战要等 v0.6+。
3. **伤害复用旧链路**：对船就是船体/桅杆/舵那三处损伤（船体→阻力、桅杆→帆面积、
   舵→转舵效率），没有新开一套。

## 3. 陆战循环

```
120 米外遭遇 → 齐射（8 秒一个节拍，装好的人一起打）→ 硝烟遮住视线 5–8 秒
→ 当地人冲到 4 米内 → **装填间隙**：对面正低头装药（×1.35 命中、×1.25 伤害）
→ 有长矛/剑盾的人顶住，只带火枪的人被冲垮 → 士气崩了就跑 → 打完算账
```

四个数决定了这一期的体验，全部在 `weapons.json` 里：

| 数 | 值 | 它管什么 |
|---|---|---|
| 火绳枪 `reload_s` | 42 秒（熟练 26） | 两发之间的空白 —— 近战武器存在的理由 |
| `formations.volley_gain` | 散兵 0.35 / 密集 0.9 / 横队 1.0 | 齐射系数（十人密集 = ×1.9） |
| `crew_quality.melee_damage_mult` | 1.35 | 钢制武器 + 甲具：船员在近战里占优 |
| `local_warriors.morale` | 0.66 | 当地人被打崩的阈值（死一个人掉 0.05） |

调这三四个数的时候有个反直觉的地方：**先算"几轮齐射"再算"近战"**。
遭遇距离 120 米、齐射间隔 8 秒、装填 42 秒 —— 所以真正打出去的是三轮齐射，
不是十轮。把遭遇距离设成 28 米（第一版就是这样）时，齐射只有一轮，
于是"火枪厉害"和"近战有用"这两件事都测不出来。

## 4. 伤亡与当地文明

**伤亡写回名册**（验收第 5 条）：

```
倒地 → 有外科医生 + 药品 → 救回来（health 0.45，消耗一箱药）
     → 没有 → 死：名册里留名字、航海日志留讣告、ending_score["crew"] -= 1、
              旗标 lost_<id>、并且**再也不会被派活**
```

**当地文明**（`scripts/culture.gd`）：一个态度值 + 三档标签，行为改态度：

| 行为 | 态度 | 结果 |
|---|---|---|
| 交换 / 送礼 | +0.30 / +0.20 | 两回交换就到"友善" |
| 不打扰 | +0.05 | 中立 |
| 越界 | −0.10 | |
| 开火 | −0.60 | 两轮就"敌对" |
| 抓人当向导 | −0.80 | 立刻翻脸 |

态度 ≥0.35 = 友善、≤−0.35 = 敌对；**只有敌对的才会主动打你**。
M6 只做到"上岸会不会打起来"，港口态度与事件链留给 M7。

## 4.5 上场的是谁：把"凭空刷出来的人"改成"本来就在的人"

这一节记两次返工 —— 两次都是"设计写了、代码也对，但游戏里不是那么回事"。

### 一、第一次：根本打不起来（接线缺口）

上面那张表、`begin_land_battle()`、HUD 里那句"上岸就可能打起来"、28 条断言全都在，
但**没有任何地方在游戏里开过一场仗**：`begin_land_battle()` 只在**截图脚本**里被调用过，
而"开火 / 抓人 / 越界"这些能把态度打下去的**玩家动作一个都没接进游戏**。
于是当地人永远停在"中立"，陆战这一整期在正常玩法里摸不到，
连 M7 那条因果链的第一环都开不了头。

**正门**其实是 M5 就做好的那张**「部落冲突」抉择卡**（走到村子就弹）：交换 / 慢慢退回 /
**开火吓退他们** / 抓一个人当向导 —— 可它的四个选项以前**一点没碰 `culture`**
（只改心情、分数、旗标）。所以卡片上写着"开火吓退他们"，选完当地人还是"中立"。
现在卡片的选项直接喂 `culture.gd` 里那张表（数据里多一个 `culture` 键，
`dilemma.gd` 那一格接上），于是：**你在村里选了什么，决定了他们下一段会不会打你**。

### 二、第二次：打起来那一刻，凭空刷出两队人（用户 2026-10-02 指出）

原话："触发战斗后会凭空刷新出来一批人和敌人。参与战斗的应该是船长带领的人和敌人。
两者本来就应该存在。" —— 他说得对：`LandBattle.setup()` 是拿 `captain_pos` 当原点、
两边各排开 60 米**当场造**两队单位出来，跟"你带的那队人"和"岛上住的那伙人"没有关系。

改法（`scripts/locals.gd` + `land_battle.gd` 的两个口子）：

| 谁 | 以前 | 现在 |
|---|---|---|
| 船员侧 | 在 origin 两侧排成合成队形 | 用**岸上队形里每个人真正站的位置**（`crew_positions`） |
| 当地人侧 | `locals_count` 个新造的单位 | 就是岛上那批 `LocalGroup.units` —— **同一个对象**，位置/伤员/倒下的都带着 |
| 什么时候开打 | 脚本直接调 `begin_land_battle()` | 他们**从村子里走过来**：最近的人进到 120 米（`START_GAP_M`）才咬上 |
| 打着的时候 | 队伍照样列队前进（画面上两批人） | 队伍原地不动；画面上只有一批人（战场那批） |
| 打完之后 | 战斗单位留在原地，队形的人还在别处 | 战后的站位与伤亡**写回队形**，画面从"战场"原地切回"队形" |

所以你**看得见他们走过来**（岸上时，村子那伙人一直画在图上），打完**人也是真的少了**
（不会下一场又满血站回村里）。存档也带着他们（`ShipState.locals`）。

### 三、现在怎么打到一仗

| 在哪 | 怎么用 | 会发生什么 |
|---|---|---|
| 走到**村落**（左键点过去） | 弹出「部落冲突」卡 | 选**开火吓退他们** → `fire` −0.60 → **当场翻脸**（他们就站在十几米外，下一步就围上来） |
| 岸上按 **`B`** | 船员向天开枪示警 | 同一个 `fire`：**两枪翻脸**；消息条会写出他们现在的态度（这是个随手的入口，正门仍是那张卡） |
| 走到村落，且中立/友善 | —— | 和平接触：他们比划着要交换，态度 **+0.05**（`leave_alone`），不会凭空开打 |
| 已经敌对 | 一次登陆只打一场 | 他们**从村子走过来**，进到 120 米就咬上（12 人对你的登陆队，天气决定哑火） |

打起来之后：`G` 齐射/各自为战、`H` 冲、`J` 退。伤亡进讣告与结算的"船员成果"。

**最快的验法**（×36 下约 3 分钟）：出海 → 朝绿岬岛开 → 到滩头附近 `X` 抛锚、`L` 带人上岸 →
左键点**村落**走过去 → 卡片选"开火吓退他们" → 他们围上来。
（想跳过卡片：岸上按 `B` 两下也一样。）

证据：`.shots/46_land_battle.png`（本地人那 12 个红点正从村子走过来，你的队伍在对面）。
`test_land_battle` 的"上岸到底会不会打起来"那一节把这一串全演了一遍（28 → **51 项**）：
卡片选开火真的翻脸、他们是一步步走过来的（单步 1.70 米 ≤ 3.4 米/秒 × 0.5 秒）、
战斗里的两队就是本来那两队（当地人 12/12 是同一个对象）、打完真的少了人、
打完队形从战场原地接手。

## 5. 怎么验证

```powershell
& $g --headless --path . --script res://tests/test_weapons.gd      # 48 项（四项硬指标）
& $g --headless --path . --script res://tests/test_land_battle.gd  # 28 项（复现/近战/死亡/文化）
```

| 验收 | 证据 |
|---|---|
| 1. 四项硬指标全过 | `test_weapons`：装填 ≥30s（隼炮 ≥120s）、密集齐射 = 各自为战的 2.53 倍（模型层实测 3.17 倍）、干燥 3.5% / 大雨 31.5%（一千发的确定性硬币贴着模型值）、霰弹砸船只有实心弹的 8% 且对 80–200 米外的人零杀伤 |
| 2. 10 对 10 可完整复现 | `test_land_battle`：两场同样的遭遇跑 240 秒，逐单位的 state/health/morale/shots/hits 字符串**完全一致**；伤亡名单与统计也一致（那场打下来：船员倒 4、当地人倒 10） |
| 3. 只带火枪会被打死 | 把 10 个人全换成火绳枪 → 全员被打崩（倒 10）；混编（4 火枪 + 4 长矛 + 2 剑盾）只倒 4 人 ✔ 机制是"装填间隙被冲击"的 ×1.35/×1.25 |
| 4. 雨天哑火 + 没弹药打不了 | `test_weapons`：模型层与实测两路；`test_land_battle`：把火药铅弹清空 → 整场 **0 发** 打出去 |
| 5. 死亡被记录 | `test_land_battle`：上岸开打 → 真的死人（3 人）、`ending_score["crew"] < 0`、航海日志里有讣告、消息条上写了结果、阵亡者不再担任岗位 |

画面证据：`.shots/46_land_battle.png`（两队对射：金/蓝是船员、红是当地人，中间那团灰是硝烟）。

## 6. 已知限制

| 限制 | 说明 | 什么时候 |
|---|---|---|
| **不做船对船** | 卡片明确划出去了；船对岸也只做到"接口与损伤链路"（真正双向轰击留给 v0.6+ 的海战） | v0.6+ |
| 联机下的判定归属只摆了接口 | 射击方广播"谁向谁开火"、受击方权威判命中 —— 单机可跑，双机对战没做 | v0.6+ |
| 战场是"平地" | 没有地形、掩体、建筑；单位只按距离与士气行动 | v0.6+ |
| 当地人的战术很笨 | 最近的敌人 + 直冲；不会包抄、不会撤退重整 | v0.6+ |
| 硝烟只影响一个显示量 | `visibility_m` 掉了，但寻敌不受它限制（还没做"看不见就不开枪"） | v0.6+ |

## 7. 这一期踩到的坑

| 坑 | 症状 | 对策 |
|---|---|---|
| 遭遇距离只有 28 米 | 齐射只来得及打一轮，"火枪厉害"与"近战有用"两件事都测不出来 | 起始间距 120 米（`START_GAP_M`）：三四轮齐射之后再见面 |
| 战斗单位用局部坐标 | 仗打在世界原点（地图西北角），画面上一片空 | `setup()` 收一个 `origin`：打起来的地方就是队伍站的地方 |
| 小样本比哑火率 | 一场战斗只有 11 发，"雨天 36% vs 晴天 18%" 的 3 倍断言时通时不通 | 方向断言（`rain > dry`）+ 一千发的大样本断言贴着模型值 |
| 近战优势调不出来 | 混编队也被打崩（倒 10 vs 倒 10），验收第 3 条无从谈起 | 把"近战优势"写成数据（`crew_quality`），用 `--mode scan` 扫出 1.35 |
