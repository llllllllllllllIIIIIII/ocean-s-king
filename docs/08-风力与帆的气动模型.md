# 风力与帆的气动模型（Day 3 定稿）

> 这份文档回答一个问题：**为什么船会这么动。**
> 代码在 `scripts/ship_physics.gd`（力）与 `scripts/ship_dynamics.gd`（运动），
> 参数在 `data/defs/ship_physics.json`，标定工具是 `tools/aero_prototype.py`。
> 三处共用同一组数字 —— 改一处必须重跑 `python tools/aero_prototype.py --mode criteria`。

---

## 1. 这条链子

```
真风 TWS/TWD ──┐
               ├─→ 视风 = 真风 − 船速矢量
船速 u/w ──────┘        │
                        ├─→ 帆的攻角 α → Cl(α) / Cd(α)
帆的实际收放角 ─────────┘        │
                                 ├─→ 升力 L ⊥ 视风、阻力 D ∥ 视风
                                 │        │
                                 │        ├─→ 推力（沿船首方向）→ 对抗 船体阻力 + 诱导阻力
                                 │        └─→ 侧力 → 龙骨顶住 → 顶不住就侧滑/横倾
                                 ▼
                        积分出 位置 / 艏向 / u / w，横倾是派生量
```

**唯一的数据流原则**（AGENTS.md 铁律 5）：玩家 → 船员 → 帆 → 船 → 表现。
船的位置和速度**只有** `scripts/ship_dynamics.gd` 能写，静态检查见
`tools/check_motion_ownership.py`。

## 2. 力的公式

### 2.1 视风与帆

视风（船体系，+x 船首、+y 右舷）= 真风速度矢量 − 船速矢量 `(u, w)`。
帆的攻角 `α = 视风来向与帆弦线的夹角`，查表得 `Cl(α)/Cd(α)`：

```
q     = 0.5 · ρ_air · |视风|²
L     = q · A · Cl(α)        ⊥ 视风
D     = q · A · Cd(α)        ∥ 视风
主帆 A = 62 m²，前帆 A = 28 m²（前帆攻角 = 主帆攻角 − 8°）
```

`Cl/Cd` 表（软帆含桅杆干扰，18° 附近最大升力，之后失速）在
`data/defs/ship_physics.json` 的 `sail_polar`。

### 2.2 船体阻力

```
R(u) = c_lin·u + c_quad·u² + c_wave·u⁴
```

`c_wave·u⁴` 是**船速上限**，不能省。省掉的后果实测过：顺风时帆的推力随视风一起
长大（跑得越快视风越大），纸面能算出 19 节的卡拉维尔。

### 2.3 龙骨与侧滑（"能不能顶风走"的决定性物理量）

龙骨能提供的侧向力是有上限的，上限与**水的动压**成正比：

```
F_max = k_stall · (u² + w² + u_min²)
```

侧向力 `F_lat`（= 帆的侧向分力）的去向：

| 情况 | 谁来顶 | 侧滑 w |
|---|---|---|
| `|F_lat| ≤ F_max` | 龙骨 | `w = F_lat / k_lat` |
| `|F_lat| > F_max` | 龙骨到顶，剩下靠船体横流阻力 | `w = F_max/k_lat + √((|F_lat|−F_max)/c_cross)` |

诱导（漂移）阻力 = 侧向力沿水流方向的分量：

```
R_ind = |F_lat| · sin(侧滑角) = |F_lat| · |w| / √(u² + w²)
```

**这里有一个必须记住的坑**：诱导阻力要用**实际侧滑速度 w**，不能用"帆想推出来的
侧向力有多大"去反推一个失速角。第一版就是那么写的（`tan(min(atan(w/u)+λ0, 80°))`），
结果在 u→0 时阻力发散，船从静止**永远推不动自己**。换成上面这套以后，
静止起步（w=0 → 诱导阻力=0）与顶风死区（船慢 → 龙骨顶不住 → 侧滑长大 → 阻力暴涨）
两件事才同时成立。

### 2.4 横倾

```
φ = asin( F_lat · h_ce / (m · g · GM) )      再乘 cos φ 折减推力
```

60 吨 / GM 0.55 m / 受力中心 10.5 m：横风 15.6 节时约 8°，19.4 节时约 12°。

## 3. 稳态求解（为什么这么绕）

前进方向的平衡是 `fx = R(u) + R_ind(u, w)`。两边随 u 的变化方向相反，
所以"总阻力 − 推力"是一条 **U 形曲线**，可能有两个根：

* 小根 = 不稳定的平衡（船会被推回静止）
* **大根 = 真正的稳态**（船稳定巡航的速度）

所以 `solve_surge()` 的做法是：在 u ∈ [0.05, 30] 的网格上找**满足条件的最大 u**，
再在它和下一个网格点之间二分。一个 u 都不满足 → 这个配平推不动 → 返回 0。

另外，松弛迭代在"刚好推得动/刚好推不动"的刀尖上会进 **limit cycle**，
最后算出一个**根本不是稳态**的正速度（顺风 180° 时最明显）。
因此每次求解末尾都做收敛校验：`|u_new − u| ≥ 0.05` 就判定这个配平站不住。
Python 与 GDScript 两侧都做了，否则两边的极坐标会对不上。

## 4. 标定与验收

**唯一命令**：

```powershell
python tools/aero_prototype.py --mode criteria      # 四项硬指标
python tools/aero_prototype.py                      # 再加极坐标表
python tools/aero_prototype.py --mode tune --param k_stall --lo 400 --hi 1400
python tools/aero_prototype.py --mode trim-table     # 重新生成船员配平表
```

真风 8 m/s（15.6 节）下实测（2026-10-01）：

| 指标 | 要求 | 实测 | 结果 |
|---|---|---|---|
| ① 逆风死区边界 | 35–40° | **37°** | ✅ |
| ② 最快舷角 | 约 90° | 90°（6.46 节） | ✅ |
| ③ 顺风 vs 横风 | 顺风明显慢 | 5.04 vs 6.46 节 | ✅ |
| ④ 最佳抢风角 | 40–45° | **45°** | ✅ |

其它风速下也稳：真风 5–14 m/s 时死区边界 34–38°、最佳抢风角 45–48°、横风始终最快。

### 关键参数（`data/defs/ship_physics.json`）

| 参数 | 值 | 作用 | 动它会怎样 |
|---|---|---|---|
| `k_stall` | 800 N/(m/s)² | 龙骨侧向力上限 | 变大 → 死区边界变小（更容易顶风） |
| `c_cross` | 12000 N/(m/s)² | 船体横流阻力 | 变大 → 失速后漂得少、死区边界变小 |
| `c_lin`/`c_quad` | 137 / 172 | 摩擦与兴波 | 整体快慢，也会轻微改变极坐标形状 |
| `c_wave` | 9.0 N/(m/s)⁴ | 船速上限 | 决定顺风会不会跑飞 |
| `k_lat` | 20000 N/(m/s) | 龙骨侧向刚度 | 决定"侧滑角"读数（横倾几乎不变） |

**调参顺序**：先 `k_stall` 把死区边界放到 35–40°，再看 `c_cross` 与 `c_lin/c_quad`
把最佳抢风角收进 40–45°。这两件事互相拉扯（边界变高，抢风角也会跟着变高），
所以必须用 `--mode tune` 扫，不要凭感觉改一个数。

### 船员配平表

`data/defs/trim_table.json`：`--mode trim-table` 生成，
给出"真风速 × 真风角 → 最佳主帆攻角 + 预期船速"。
运行时 `scripts/crew.gd` 只做双线性插值，比在游戏里现场搜索便宜三个数量级。
Day 4 的指挥链路会在这张表上再加技能、疲劳与执行耗时。

## 6. 已知简化（后面要留意）

1. **没有抢风换舷**：目标航向落在死区里，船会停在原地等 —— Day 4 的航海官要负责换舷。
2. **横倾只是数字**：`φ` 已经算出来并参与推力折减，但还没画到船上（帆的透视压缩也没做）。
3. **风场只有全局缓变 + 阵风**：岛屿背风区、洋流带还没做（Day 6）。
4. **没有考虑波浪与舵阻**：舵只影响艏向，不产生额外阻力。
5. **单帆模型是"两个独立翼面"**：没有主帆与前帆之间的缝隙效应（slot effect），
   所以顶风性能比真实卡拉维尔略乐观 —— 这正好符合"死区边界 37°"的设计目标。
6. **损伤未接入**：桅杆/舵/船体的损伤还没影响气动（Day 5–6）。
